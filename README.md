ship_sim
========
A multipurpose space ship simulator.  
Built mainly as a Rust learning project, it is intended to be used to supplement sci-fi TTRPGs.

Main Feature Goals
--------
1. Navigation system with course plotter and position tracking
2. Calculate and compare courses with different burns/parameters
3. Real planet positions computed for Sol
4. Swappable solar systems
5. Ship properties tracked and taken into consideration
6. Browser-facing CLI
7. GM/Player modes

Additional Feature Goals
--------
1. Ship systems/substems/consumables fully tracked
2. GM created failures/ships/stations
3. GUI
